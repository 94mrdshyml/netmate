# Session log

One file per working session, named `NN-short-title.md` (NN is the next number; two branches picking the same number is harmless because the titles differ). Earlier files are never edited. Because every session adds its own file, two open pull requests can never conflict here.

At the start of a session read only the two files with the highest numbers. The format is in `.claude/skills/log-session/SKILL.md`.
