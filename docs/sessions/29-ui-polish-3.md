# 29. UI polish: column edges, one icon thickness, empty screens, "..." menu, loading line (2026-10-23)
- Branch / PR: feat/ui-polish-3. Cut from `feat/column-border` (the small border change the owner asked for, pushed but never opened as its own PR) with main (#48, status emails) merged in. No other PR was open. The old `feat/column-border` branch is now superseded by this one.
- Owner asked to fix six things from my list of ideas: icon line thickness, bare empty screens, the outside of the column, the profile cover in dark mode, the bin icon into a "..." menu on each post, and a loading feel after a tap. Not asked for now: the compose box on Home, the sign-in and sign-up look, photos in posts.
- Done:
  - Column edges: on a screen wider than the column the page around it is a shade apart (5% of text colour in the page colour) and a 1px hairline runs down each edge. First built as an overlay strip; replaced by making `body` the column's width with its own border, which stays exactly on the column's edges beside a scrollbar. The fixed bottom bar gets the same two lines so they are not cut at the bottom. Phones and `/hq` have neither.
  - Icons: one line thickness (1.75) for every icon. The `strokeWidth` option is gone from `Icon`, so nothing can drift again. Added `users` and `more-horizontal`.
  - Empty screens: an `EmptyState` component (icon in a soft circle, plain line, hint, optional button) used on Home (both tabs), Alerts, profiles (posts and replies), followers and following, replies on a post page and every search case. Wording kept so existing checks still match ("Your feed is empty", "No alerts yet.", "No posts found", "No one found").
  - Profile cover in dark: the default cover is 32% brand colour on the page colour (it was 14%, near black in dark).
  - "..." menu: `PostMenu` replaces the bin button on your own posts. It opens a small flat menu (Delete post), upward near the bottom of the screen, closes with Escape or a tap outside, and deleting still asks first. Posts by other people have no menu.
  - Loading line: `NavigationProgress` in the member layout draws a 2px brand line that starts when a link to another screen is tapped and finishes when the new address arrives (gives up after 12 seconds). A route-level loading file is still not used because it makes missing pages answer 200.
- Tests: `look.spec.ts` gained: column edges and page shade (wide, phone, `/hq`), one icon thickness on three screens, empty states, dark cover colour, the "..." menu (tap sizes, Escape, tap outside, then deleting), and the loading line (watches its phase go loading then done). `posts.spec.ts` and `search.spec.ts` now open the "..." menu before deleting (the bin they clicked is gone, on purpose); posts.spec also checks that someone else's post has no menu. `social.spec.ts` checks the "Find people" button on an empty Following feed.
- Open: the hover colour of the "..." items cannot be felt in the phone emulation. `test:theme` and `test:a11y` still do not exist.
