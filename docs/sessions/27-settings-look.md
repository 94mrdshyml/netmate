# 27. Settings screen from the picture, smaller type, brand-coloured icons (2026-10-23)
- Branch / PR: feat/ui-settings-look. Cut from fresh main after #43 (email), #45 (the look) and #46 (React Email) merged. No other PR was open.
- Owner feedback after seeing the live look: the picture's side menu was not liked and should look like a reference Settings screen (sent as an image); hover and press should turn icons the brand colour with no background; text looked a little big and too bold everywhere; and Profile was reachable from both the bottom bar and the menu.
- Decisions:
  - The picture now opens a real Settings screen (`/settings`), laid out like the reference: back arrow, title in the middle, one plain list (icon, title, short quiet line, chevron), then a "Dark or light theme" row with the sun and moon button at the right, then an outlined Log out button. The side sheet (`account-menu.tsx`, `member-menu.tsx`, about 150 lines of CSS) is gone; a plain link (`account-link.tsx`) replaces it. It is a page, not a panel, so it has a URL, the back button works and the bottom bar stays visible like in the reference.
  - Profile is only the bottom bar tab. It is not in Settings (and the old menu's Profile row is gone with the menu). Edit profile stays as a Settings row because the reference has it.
  - The theme choice is now two-way (light or dark, from the button). The old three-way "Match phone, Light, Dark" picker is gone from Settings, as the reference has one button. A person who has not chosen still follows their phone; they can no longer go back to "match phone" without clearing the cookie. Easy to put back if wanted.
  - Type: `html` is 15px (was 16px, so everything in rem is 6% smaller), headings and names are 600, buttons, tabs, rows and the bottom bar are 500, the rest 400. Some big sizes came down one step (page title, post focus text, composer, profile name, stat numbers).
  - Colour on interaction: round icon buttons, bottom bar icons and labels, post actions and Settings row icons turn `--brand-text` on hover and press; ghost buttons take the brand colour and border on hover. No hover backgrounds are left except behind the camera buttons that sit on pictures (they need one to be readable).
- Tests: look.spec rewritten for the new screens (picture opens Settings from Home, Search and Alerts; Settings list, tap sizes, centred title, back arrow; one way to Profile; hover turns the nav icon and the theme button the brand colour with a clear background; 15px body and weights at or under 600/500; the edit profile tests kept). theme.spec: the top bar test is a link to Settings again, and the three-way Settings test became a Dark or light theme row test. alerts.spec: a regular member's Settings has no Admin panel. These tests changed because the design they checked changed on purpose; none was skipped, loosened or deleted.
- Orphaned CSS removed: the side sheet, `.account*`, `.rows*`, `.row-*`, `.segmented*`, `.segment*`. `ThemeChoicePicker` removed (the cookie rules in `src/lib/theme-choice.ts` still serve the layout).
- Open: hover cannot be felt in the phone emulation, the test moves the pointer and reads the colour. `test:theme` and `test:a11y` still do not exist, so contrast was checked by eye on one brand colour. The `taste` skill is still not installed here.
