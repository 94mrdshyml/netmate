# 26. React Email (2026-10-23)
- Branch / PR: feat/react-email
- Before this: #43 (`/hq/email`) and #45 are merged. The owner said "use react email", which is the approval CLAUDE.md asks for before adding a package.
- Package added: `@react-email/components` 1.0.12, pinned exactly (`bun add --exact`). It pulls in `@react-email/render` 2.0.6 and the small component packages (37 packages in all, including a markdown and a code-block package that are not used and are dropped from the bundle). Released 2026-04-09, so well over two weeks old. No other package was added.
- Done: `src/email/layout.tsx` is the one shared layout (name or PNG logo, heading, paragraphs, optional button, footer; brand colour, text colour on it, corner style and font stack written into inline styles). `src/email/render.tsx` renders it to HTML and a plain-text copy. `src/email/template.ts` keeps only the types, `pngLogoUrl` and `isWebUrl`. `sendTestEmail` now renders through React Email. The hand-written HTML builder and its escape function are gone (React escapes text).
- `bun run test:email` is new (a vitest project over `tests/email/*.test.tsx`) and runs in CI after the integration tests, as CLAUDE.md lists.
- Checked in the real runtime: the integration tests render inside the Workers runtime, and the e2e test email goes through the OpenNext build. Worker size after the change: 2.25 MB gzipped (limit 10 MB).
- Tests: 17 in `tests/email/layout.test.tsx` (a real page; brand colour, radius and font in the styles; every corner style; extreme brand colours; plain-text copy; logo as PNG or name as text; escaping of a hostile name, heading and message; buttons with bad addresses left out; odd font characters stripped; no script, link tag, web font or outside address). The unit tests for the old builder moved here; `isWebUrl` has its own unit test.
- Notes: React Email puts a hidden preview line before the body, and its plain text writes the heading in capitals. The layout writes "Sent by <name>." as one string, because two adjacent text pieces render with comment markers between them.
- Open: only the test email uses the layout so far. Pending, approved, rejected, verification, reset and welcome emails are next, each as a small component inside this layout. React Email does not draw SVG either, so an SVG-only logo still shows the name as text.
